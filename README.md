# Metodologías

App personal con las herramientas y el paso a paso de Lean Manufacturing,
Lean Six Sigma, Kaizen, Design Thinking y TPM.

Se instala en el celular desde el navegador: al abrirla aparece abajo el
botón **Instalar**, y queda con su propio icono entre las apps.

## Estado

- **Lean Manufacturing** — completo, los 5 principios con sus herramientas.
- Lean Six Sigma, Kaizen, Design Thinking y TPM — pendientes.

## Cómo actualizarla

1. Reemplazar `index.html`.
2. Subir el cambio a `main`.
3. Si se cambia algún icono o el manifest, subir el número de `CACHE` en `sw.js`
   (por ejemplo `metodologias-v2`) para que los celulares ya instalados
   descarguen la versión nueva.
